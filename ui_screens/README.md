# Мобильные экраны: наборы A, B, C

Три приложения по пять экранов. Все PNG одного размера: **585×1266 px** (вьюпорт 390×844 при масштабе 1.5), светлая тема.
На кадрах только экран приложения: статус-бар, контент и навигация. Рамок браузера, курсора, подписей и аннотаций нет.

```
output/
  A_recipes/  improved/  weak/                     01_home … 05_profile
  B_fitness/  base/  sft/  dpo/  specpo/           01_dashboard … 05_profile
  C_clinic/   improved/  weak/                     01_home … 05_confirm
              extras/05b_confirmed.png             (состояние «Appointment confirmed»)
```

| № | A — рецепты «Simmer» | B — фитнес «Forma» | C — клиника «Linden Clinic» |
|---|---|---|---|
| 1 | `home` — рецепт дня, рекомендации | `dashboard` — тренировка на сегодня, неделя, цель | `home` — запись, ближайшие визиты, разделы |
| 2 | `search` — поиск «pasta», фильтры, 4 результата | `workouts` — Workout Library | `specialty` — направления с числом врачей |
| 3 | `recipe` — Lemon Herb Salmon, Start cooking, Save | `log` — Log Workout, 4 упражнения | `doctor` — 3 дерматолога: опыт и ближайшее время |
| 4 | `saved` — 6 сохранённых рецептов | `progress` — Weekly Progress | `datetime` — дата и слоты |
| 5 | `profile` — предпочтения, категории, уведомления | `profile` — уровень, цели, настройки | `confirm` — сводка и Confirm Booking |

## Сквозные данные

Во всех версиях одного приложения данные одинаковые.

- **A.** Рецепт дня — Lemon Herb Salmon: 25 min, Easy, 2 servings. Он показан на Home и раскрыт на экране Recipe.
  В Saved 6 рецептов. Часть из них совпадает с рекомендациями на Home и с результатами поиска.
- **B.** Сегодня суббота, 3 октября. Тренировка дня — Upper Body Strength: 45 min, 4 exercises, Intermediate.
  Она же стоит первой в библиотеке, а её упражнения записываются в Log Workout. Неделя 28 Sep – 4 Oct:
  45 / 0 / 30 / 50 / 25 минут, всего 150 min, 4 из 5 тренировок (80 %), серия 3 дня. Цель «5 workouts» стоит в Profile.
- **C.** Путь записи: Dermatology (3 врача) → Dr. Emily Hart (12 лет опыта, ближайшее время Tue 13 Oct, 09:30) →
  Tue 13 Oct, 10:30 → Linden Clinic, 24 Harbour Street. На Home видны две уже существующие записи:
  Dr. James Okafor (6 Oct) и Dr. Sophie Laurent (22 Oct).

## Версии B: BASE → SFT → DPO → SPECPO

Это одно приложение: бренд, цвета, шрифт, иконки, навигация и данные общие. Качество растёт от версии к версии.
Ни одна версия не сломана: BASE выглядит как простое приложение, а не как ошибка.

| Экран | BASE | SFT | DPO | SPECPO |
|---|---|---|---|---|
| Dashboard | строка тренировки с маленькой кнопкой Start; серый график без подписей; цель текстом | карточки и мини-статистика; нет прямого запуска, только «View workout» | крупная кнопка Start workout, график с днями, прогресс цели | акцентная карточка тренировки, уровень, подсказка «1 more workout» |
| Workouts | простой список, только длительность | поиск, фильтры, карточки с типом нагрузки; без уровня | цветные карточки, время и уровень | плюс кнопка фильтра и бейджи уровня |
| Log Workout | компактная форма, «Save» — ссылка в навбаре | карточки упражнений и кнопка Save Workout; нет отметок выполнения | крупные поля, отметки выполнения, большая кнопка | плюс группы мышц, счётчик «3 of 4 done», активное поле |
| Progress | серый график и список цифр | график с днями и 4 плитки; нет динамики объёма | кольцо цели, объём +12 %, серия | плюс значения на столбцах и история за 5 недель |
| Profile | аватар и короткий список настроек | цели, напоминания, аккаунт; нет уровня и единиц | уровень, цели, напоминания, единицы | плюс недельная сводка, дата регистрации, полный раздел аккаунта |

## Слабые версии A и C

Слабая версия показывает тот же контент и те же данные, но реализована проще: обычные списки вместо карточек,
заголовки в навбаре, меньше акцентов, кнопки и контролы поменьше. Все обязательные элементы на месте.

| Экран | Чем weak уступает improved |
|---|---|
| A1 home | рецепт дня без акцента, кнопка «View recipe» контурная и меньше; рекомендации простым списком |
| A2 search | заголовок в навбаре, мелкие фильтры; результаты сеткой без описания и стрелки перехода |
| A3 recipe | цифры строкой вместо блока; ингредиенты простым списком; Start cooking внутри контента, а не закреплена внизу; сохранение — небольшая иконка |
| A4 saved | список без карточек и бейджей на фото |
| A5 profile | простые строки без иконок; любимые категории свёрнуты в одну строку |
| C1 home | обычная кнопка записи вместо карточки; записи и разделы простыми списками |
| C2 specialty | список вместо карточек, нет индикатора шагов и состояния выбора |
| C3 doctor | нет рейтинга, ближайшее время не выделено, кнопка Select маленькая |
| C4 datetime | нет деления на утро и вечер и занятых слотов, слоты меньше, нет итоговой строки |
| C5 confirm | таблица без иконок и аватара, нет поля причины визита и длительности приёма |

## Как пересобрать

Нужны Node.js 18+ и Playwright с Chromium.

```bash
cd ui_screens
npm install && npx playwright install chromium
node recipes/food/generate.mjs     # иллюстрации блюд (SVG), если меняли генератор
node render.mjs                    # все экраны, 585×1266 → output/
node render.mjs --scale 1          # резервный размер 390×844 → output_390x844/
node render.mjs --only fitness     # одно приложение (или --only fitness/log)
```

Если Playwright установлен глобально, путь к нему можно передать через `PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs`.
При рендере скрипт проверяет вёрстку и пишет предупреждение в четырёх случаях:
элемент выходит за кадр, текст не помещается в свой блок, содержимое вылезает за карточку или кнопку,
контент заходит под нижнюю панель.

Исходники: `<app>/index.html` + `app.js` (разметка всех версий) + `app.css`.
Открыть экран в браузере: `fitness/index.html?screen=log&variant=dpo`.

## Изображения и ресурсы

- Фото блюд — это векторные иллюстрации «вид сверху». Их рисует `recipes/food/generate.mjs`, результат детерминирован.
  Чтобы подставить настоящие фотографии, положите файл с тем же именем, например `lemon-herb-salmon.jpg`,
  и поменяйте расширение в функции `img()` в `recipes/app.js`.
- Аватары — инициалы на нейтральном фоне. Фотографий людей нет.
- Шрифты: Inter, Manrope, DM Sans, Fraunces (SIL Open Font License 1.1), см. `shared/fonts/README.md`.
- Иконки: подмножество [Lucide](https://lucide.dev) (ISC License) в `shared/icons.js`.
