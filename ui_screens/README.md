# Мобильные экраны: наборы A, B, C

Три приложения по пять экранов, у каждого экрана есть две версии: `improved` (улучшенная) и `weak` (слабая).
Все PNG одного размера: **585×1266 px** (вьюпорт 390×844 при масштабе 1.5), светлая тема.
На кадрах нет рамки браузера, курсора, подписей и аннотаций.

```
output/
  A_recipes/  improved/01_home.png … 05_profile.png    weak/…
  B_fitness/  improved/01_dashboard.png … 05_profile.png    weak/…
  C_clinic/   improved/01_home.png … 05_confirm.png    weak/…
              extras/05b_confirmed.png    (экран «Appointment confirmed» после подтверждения)
```

| № | A — рецепты «Simmer» | B — фитнес «Forma» | C — клиника «Linden Clinic» |
|---|---|---|---|
| 1 | `home` — рецепт дня, рекомендации | `dashboard` — тренировка на сегодня, неделя, цель | `home` — Book appointment, ближайшая запись, разделы |
| 2 | `search` — поиск «pasta», фильтры, 4 результата | `workouts` — Workout Library, поиск, фильтры, 5 программ | `specialty` — выбор специальности (шаг 1/4) |
| 3 | `recipe` — Lemon Herb Salmon, Start cooking, Save | `log` — Log Workout, 4 упражнения, Save Workout | `doctor` — 3 дерматолога (шаг 2/4) |
| 4 | `saved` — 5 сохранённых рецептов | `progress` — Weekly Progress | `datetime` — дата и время (шаг 3/4) |
| 5 | `profile` — предпочтения, категории, уведомления | `profile` — уровень, цели, единицы, уведомления | `confirm` — Confirm Booking (шаг 4/4) |

## Сквозные данные

Названия и цифры совпадают на связанных экранах.

- **A.** Рецепт дня — Lemon Herb Salmon: 25 min, Easy, 2 servings. Он показан на Home и раскрыт на экране Recipe.
  Рекомендации на Home (Green Buddha Bowl, Shakshuka) повторяются в Saved.
- **B.** Сегодня суббота, 3 октября. Тренировка дня — Upper Body Strength: 45 min, 4 exercises, Intermediate.
  Она же стоит первой в библиотеке, а её упражнения записываются в Log Workout. Неделя 28 Sep – 4 Oct:
  45 / 0 / 30 / 50 / 25 минут, всего 150 min, 4 из 5 тренировок (80 %), серия 3 дня. Эти цифры совпадают на Dashboard и Progress.
  Недельная цель «5 workouts» стоит в Profile.
- **C.** Путь записи: Dermatology → Dr. Emily Hart (ближайшее время Tue 13 Oct, 09:30) → Tue 13 Oct, 10:30 → подтверждение.
  На Home показана уже существующая запись к Dr. James Okafor (General Practice) на Tue 6 Oct, 09:15.

## Чем слабая версия отличается от улучшенной

Запрос, структура экранов, цвета, шрифты и данные одинаковые. Слабая версия выглядит как результат более простого генератора, без явных поломок.

| Экран | Слабая версия |
|---|---|
| A1 home | вместо кнопки маленькая плашка «View» поверх фото; мета-текст низкоконтрастный; рекомендации мелкие |
| A2 search | заголовок в навбаре вместо крупного; мелкие фильтры; у результатов нет времени и стрелки открытия |
| A3 recipe | «Start cooking» — маленькая контурная кнопка внутри контента; сохранение — мелкая иконка на фото; нет блока с цифрами |
| A4 saved | нет отметки «сохранено» и мета-информации у карточек |
| A5 profile | нет уведомлений; категории свёрнуты в одну строку |
| B1 dashboard | карточка тренировки не выделена, кнопка «Start» маленькая; у графика нет подписей дней; цель показана только текстом |
| B2 workouts | нет поиска; у программ нет уровня сложности |
| B3 log | мелкие поля ввода; «Save» — текстовая ссылка в навбаре; нет отметок выполнения |
| B4 progress | низкоконтрастный график без подписей значений; нет изменения объёма и consistency |
| B5 profile | нет уровня подготовки и единиц измерения |
| C1 home | «Book appointment» — одна из четырёх равных плиток, нет главного действия |
| C2 specialty | нет поиска, индикатора шагов и состояния выбора |
| C3 doctor | нет ближайшего времени и опыта; «Select» — мелкая ссылка |
| C4 datetime | дата выбирается выпадающим списком; мелкие слоты; выбранный слот отмечен только рамкой |
| C5 confirm | нет адреса и формата визита, нет поля причины; кнопка просто «Confirm» |

## Как пересобрать

Нужны Node.js 18+ и Playwright с Chromium.

```bash
cd ui_screens
npm install && npx playwright install chromium
node recipes/food/generate.mjs     # иллюстрации блюд (SVG), если меняли генератор
node render.mjs                    # все экраны, 585×1266 → output/
node render.mjs --scale 1          # резервный размер 390×844 → output_390x844/
node render.mjs --only clinic      # одно приложение (или --only clinic/doctor)
```

Если Playwright установлен глобально, путь к нему можно передать через `PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs`.
При рендере скрипт проверяет вёрстку и пишет предупреждение, если элемент выходит за кадр,
текст обрезан или контент заходит под нижнюю панель.

Исходники экранов: `<app>/index.html` + `app.js` (разметка обеих версий) + `app.css`.
Открыть экран в браузере: `recipes/index.html?screen=recipe&variant=weak`.

## Изображения и ресурсы

- Фото блюд — это векторные иллюстрации «вид сверху». Их рисует `recipes/food/generate.mjs`, результат детерминирован (фиксированный seed).
  Чтобы подставить настоящие фотографии, положите файл с тем же именем, например `lemon-herb-salmon.jpg`,
  и поменяйте расширение в функции `img()` в `recipes/app.js`.
- Аватары — инициалы на нейтральном фоне. Фотографий людей нет.
- Шрифты: Inter, Manrope, DM Sans, Fraunces (SIL Open Font License 1.1), см. `shared/fonts/README.md`.
- Иконки: подмножество [Lucide](https://lucide.dev) (ISC License) в `shared/icons.js`.
